# AFTER EARTH — media

The futures in this site are imagined. **The places are real:** every photograph
and every piece of footage comes from Wikimedia Commons under a free licence, and
each one is credited on the page (chapter views, comparison, and the About
section's credits list).

## How media gets here

```bash
python3 scripts/fetch-media.py          # all entries
python3 scripts/fetch-media.py ch03-tikal  # one entry
```

`scripts/media-sources.json` lists each Commons file title plus how to prepare it.
`scripts/fetch-media.py`:

1. reads the author, licence, source page and GPS position from the Commons API;
2. downloads a **standard-size thumbnail** (1920 or 3840 px) — not the original —
   as Wikimedia asks of automated clients, one request at a time, honouring any
   `Retry-After`;
3. writes responsive WebP sizes to `public/media/<id>-<width>.webp`;
4. for footage: takes Commons' own transcode, trims a short section, removes the
   audio and loops it without a visible seam — either crossfading the end into
   the start or, for moving drone shots, playing forward then back (“ping-pong”).
   Optional steps per entry: `stabilize` (two-pass vid.stab), `crop` (removes
   burnt-in captions) and `matte` (turns fog footage into a translucent mist
   layer). Output is H.264 MP4 plus a WebP poster;
5. records everything in `src/credits.json`, which the site reads at build time.

Licences that require attribution (CC BY / CC BY-SA) are satisfied by the on-page
credits; adaptations (crop, resize, re-encode, trim, loop) are stated there too.

## Alignment of the comparison pair

Repeat photographs share a viewpoint but not a frame. `scripts/align-pair.py`
matches SIFT features on the stable rock face, estimates a similarity transform
(rotation, uniform scale, shift — no stretching), warps 2020 onto 1914 and crops
both to the largest square they share. Measured result: skyline ridges coincide
to within ~0.5 % of the frame.

## Not available

* **No real footage of the hero view exists**, so the hero is the photograph
  with a moving mist layer made from separate, real fog footage (credited).
* **No real “future” imagery exists**, so chapter timelines change the imagined
  narrative while the photograph stays what it is: today's view of a real place.
* **The comparison's “2120” era** is shown as *not yet photographed*.
* **Recorded ambience:** none yet — sound is synthesised live in the browser
  (wind, water, birds). Add a loop via `MEDIA.audio.ambient` in `src/media.js`.
